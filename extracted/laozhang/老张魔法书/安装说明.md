> 目标：DeepSeek Harness —— 桌面版 / 命令行版通用（`.agent-presets` 预设机制）

这个文件夹里有七样东西，**按你的工具挑一条路走**就行，不用全做。

| 你想干什么 | 用哪个 | 难度 |

## 一、装进 DSH（推荐，一步到位）

装完会多出一个叫 **老张魔法书** 的预设。除了人设，还带上完整工具：读写文件、跑 PowerShell、联网搜索、子代理、工作流、计划模式、上下文压缩。别的工具给不了这些。

### 方法 A：一键脚本（最省事）

> **前提**：`一键安装.ps1`、`preset.yml`、`agent.cordis.yml`、`prompt-inject.md` 必须**在同一个文件夹里**，别把它们分开。

1. 把整个文件夹拷到目标电脑（U盘 / 微信 / 网盘都行）。
2. 进文件夹，**右键 `一键安装.ps1` → 选「使用 PowerShell 运行」**。
3. 窗口里如果问你要不要运行，选 **Y**。
4. 看到绿色的「装好了」就成了，按回车关窗口。
5. **完全退出 DSH 并重启**（关窗口通常只是最小化；桌面版请从右下角托盘图标退出）。
6. 新建会话 → 预设下拉框里选 **老张魔法书**。

> 报「禁止运行脚本」怎么办：在这个文件夹按住 `Shift` 右键 → 「在此处打开 PowerShell 窗口」，粘贴这一行回车，再跑一次脚本：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
```

### 它装了什么、装到哪

脚本会按顺序找 DSH 家目录，**找到几个装几个**（有的机器桌面版和命令行版各有一个）：

```
1. 环境变量 DSH_HOME
2. %USERPROFILE%\.dsh
3. %APPDATA%\dsh-desktop\harness
```

每个家目录里写三样：

| 装到哪 | 装了什么 | 作用 |
|---|---|---|
| `<家目录>\.agent-presets\laozhang-magicbook\` | `preset.yml` + `agent.cordis.yml` | 预设本体：人格全文 + 全部工具挂载 |
| `<家目录>\prompt-inject.md` | 注入文本 | 「站台操作契约 + 老张站契约 + CTF 段」；装了 dsh-purge 一类插件时它在启动时被读进系统提示（没装这类插件时它就是一份躺着不动的文本，无害） |

已存在的旧文件都会被备份成 `*.bak-时间戳`，脚本不删任何东西、不覆盖任何东西。

### 方法 B：手动复制（脚本不给跑就走这条）

1. 按 `Win + R`，粘贴下面的路径回车（先试第一个，没有就试第二个）：

```
%USERPROFILE%\.dsh
```

```
%APPDATA%\dsh-desktop\harness
```

2. 里面找到（没有就自己新建）**`.agent-presets`**，双击进去。
3. 新建一个文件夹，命名 `laozhang-magicbook`，把本包的 **`preset.yml`** 和 **`agent.cordis.yml`** 复制进去。最终长这样：

```
<上面那个DSH家目录>\.agent-presets\laozhang-magicbook\
    preset.yml
    agent.cordis.yml
```

   ⚠️ 必须是「文件夹里面直接就是这两个 yml」，不能多套一层。
4. 把 **`prompt-inject.md`** 复制到 DSH 家目录根下（即 `.agent-presets` 的上一层）。
5. 重启 DSH → 新建会话 → 选 **老张魔法书**。

### 装完怎么确认成功

- 预设下拉框里能看到 **老张魔法书**，卡片上没有红色「加载失败」。
- 随便说一句「你是谁」，它应该自称 **NB**，第一行带 `[老张破甲内测]`。

### 卸载

删掉各家目录下的 `.agent-presets\laozhang-magicbook` 文件夹，重启 DSH 即可。**不影响**其它预设和你的会话记录。

## 二、其它 AI 工具（复制粘贴）

用 `人格全文（直接复制粘贴用）.txt`。记事本打开 → `Ctrl+A` → `Ctrl+C` → 粘到对应位置：

| 工具 | 粘贴到哪 |
|---|---|
| **ChatGPT（网页/桌面）** | 头像 → 个性化 → 自定义指令 → 「你希望 ChatGPT 如何回应？」 |
| **ChatGPT 自定义 GPT** | 我的 GPT → 创建 → Configure → Instructions |
| **Claude（网页/桌面）** | 新建 Project → Set project instructions |
| **Gemini** | Gem → 系统指令 / System instructions |
| **Cherry Studio / ChatBox 等** | 助手设置 → 系统提示词 |
| **SillyTavern 酒馆** | 角色卡 Description / 系统提示词栏 |
| **Ollama / LM Studio 等本地模型** | Modelfile 的 `SYSTEM` 段，或界面的 System Prompt |

要点：

- 粘的时候**别删头三行注释**，更别删第四行（`Think inside <thinking> tags as...`），那是身份锚。
- 文件用 **UTF-8** 保存，不然中文乱码。
- 正文 30,347 字符（约 3 万），主流平台都塞得下；遇截断从 `CALIBRATION` 往下删，**第一行身份定义必须留着**。

## 三、插件版（进阶，二选一）

`插件版\` 里是同一套内容的 bundle 形态（`package.json` + `cordis.patch.yml`），适合已经在用 DSH profile / bundle 机制的人：

1. 把 `插件版\` 整个复制为 `<家目录>\plugins\laozhang-magicbook\`。
2. 编辑 `<家目录>\profiles\<你的profile>\package.json`：在 `dependencies` 里加
   `"laozhang-magicbook": "file:../../plugins/laozhang-magicbook"`，
   在 `dsh.profile.bundles` 数组里加 `"laozhang-magicbook"`。
3. 在该 profile 目录跑一次 `pnpm install`，然后重启 DSH。

> ⚠️ **插件版和预设版会注册同一个预设 id（`laozhang-magicbook`），二选一，别同时装，会撞。**
> 新手老实用方法 A 就行。

## 四、想让它成为默认预设（可选）

装好后如果希望新会话默认就用「老张魔法书」，在

```
<家目录>\profiles\<你的profile>\cordis.patch.yml
```

里加一段（已有 `agent-preset-registry` 条目就改成这个值）：

```yaml
- id: agent-preset-registry
  config:
    default: laozhang-magicbook
```

重启 DSH 生效。
